# Code of conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1. The short version:

- Be direct about code and kind to people. A blunt review of a patch is welcome; a remark about the person who wrote it is not.
- Assume the other person is trying to make the library better. Most disagreements here are about trade-offs, and the benchmarks page exists so that they can be settled with numbers.
- No harassment, discrimination, or personal attacks, anywhere the project happens: issues, pull requests, discussions, and any chat about it.

Reports go to the maintainer listed in `SECURITY.md`, or through GitHub's report feature on the specific comment. Reports are read by the maintainer only, answered within a week, and acted on in proportion: a warning, a temporary block, or a permanent one. The reporter is told the outcome.
